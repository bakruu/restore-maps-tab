# Privacy Policy — Restore Maps Tab

**Last updated: August 16, 2026**

Restore Maps Tab is designed to operate entirely within the user's browser.

## Data Collection

Restore Maps Tab does not collect, store, transmit, sell, or share personal information or browsing data.

## Search Queries

The extension reads the current Google Search query locally in the browser solely to construct the Google Maps destination when the user clicks the restored Maps tab.

Search queries are not collected, stored, logged, or transmitted by the extension to the developer or any third-party server.

When the user chooses to open Google Maps, the search query is included in the Google Maps URL as necessary to perform the requested Maps search.

## Analytics and Tracking

Restore Maps Tab does not use:

* Analytics services
* Tracking technologies
* Advertising networks
* Telemetry systems
* Developer-operated remote servers

## Local Storage

Restore Maps Tab does not currently store user data using browser storage.

## Permissions

The extension only operates on the Google Search pages declared in its extension manifest and does not request unnecessary browser permissions.

## Third-Party Services

When a user clicks the restored Maps shortcut, the browser navigates to Google Maps. Google's services are governed by Google's own terms and privacy policies.

Restore Maps Tab is not responsible for the data practices of third-party websites or services.

## Changes to This Policy

If a future version of Restore Maps Tab introduces functionality that changes its data practices, this privacy policy will be updated accordingly.

## Contact

For privacy questions, bug reports, or other concerns, please use the Issues section of the project's GitHub repository.

## Disclaimer

Restore Maps Tab is an independent third-party browser extension and is not affiliated with, endorsed by, sponsored by, or officially associated with Google LLC.
